Watch an AI agent get gated, approved, and caught tampering.

air-gate sits between an AI agent and its tools. Risky actions pause for human approval, and every decision is written to a tamper-evident audit chain. Try it: run some agent actions, approve one, then tamper with the log and hit verify.

🔒 100% in your browser.  Real HMAC-SHA256 & Ed25519 signing via Web Crypto. No server, nothing leaves this page.

Signing algorithm

This browser has no native Ed25519 in Web Crypto — falling back to HMAC for signing. The concept still applies: with Ed25519 the public key verifies without being able to forge.
